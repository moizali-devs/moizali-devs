## DevLens

RAG system for natural-language codebase Q&A. Uses AST-based chunking via tree-sitter (function and class boundaries, not token count) instead of naive text splitting, so retrieval returns complete, meaningful code units with exact file and line citations. Runs fully local (Ollama + ChromaDB) or cloud (OpenAI + Pinecone) from the same pipeline.

Stack: Python, LlamaIndex, ChromaDB, tree-sitter, FastAPI

[Repo](https://github.com/moizali-devs/devlens) · [Live demo](https://devlens-six.vercel.app)
